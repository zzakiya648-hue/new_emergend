# Reviewflow (Shortfundly / Intern)

Static site: index.html mattum thaan. Build / install onnum venam.

## Local ah paaka
index.html ah double click pannunga (Chrome / Edge).

## GitHub Pages la host panna
1. github.com -> New repository -> name: reviewflow -> Public
2. "uploading an existing file" -> index.html (and README.md) upload -> Commit
3. Settings -> Pages -> Source: Deploy from a branch -> main / (root) -> Save
4. 1-2 min apram link: https://<username>.github.io/reviewflow/

## Pages
- Dashboard: counts + recent entries
- Assignments: add, open/close correction, next review, approve, history
- Chat: chatbot la type panni ellam pannalam ("add assignment", "open correction", "approve 1", "show status")
- Email: ovvoru action ku client email draft; "Open in mail app" click panni anuppalam

Note: Data browser localStorage la save aagum (andha browser la mattum). Browser page SMTP ku direct ah pesa mudiyadhu.

# Nalla Chatbot 💬

Streamlit + Gemini chatbot: streaming replies, 4 personas, creativity slider,
suggestion chips, New chat, and chat download.

## Run
1. Python 3.10+ install pannunga.
2. `.env.example` -> `.env` nu copy panni `GEMINI_API_KEY` fill pannunga (aistudio.google.com/apikey).
3. Windows: `run.bat` double click | Mac/Linux: `./run.sh`

## Deploy (free link)
share.streamlit.io -> repo + `app.py` select -> Advanced settings -> Secrets:
`GEMINI_API_KEY = "your_key"` -> Deploy.
